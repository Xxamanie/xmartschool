## What's seeded for a colourful walkthrough

- **90 students** (3 schools × 6 classes × 5), each enrolled in **9 subjects** with **published results** spanning the full WAEC grade range (A1 → F9) so grade pills show every colour.
- **Per-student GPA** and **attendance %** computed from real records (last ~3 weeks).
- **Fee ledgers** with payments — most students fully paid (fees cleared), the 5th student in each class left partially unpaid so the **Finance** outstanding view has variety.
- **Form Master** demo: log in as `math.teacher@<code>.demo` to see the SS1A class-master view; other teachers see their subject across all classes.
- **Parents** linked to children across classes for the **Parent Portal**.
- **Staff-room chat** threads pre-populated in each school.
- **Result Access PIN** `SMART123` unlocks any student's report card (fees are cleared + results published).

### Suggested tour
1. **Creator** → log in, open the Creator Dashboard, browse all 3 schools, try *Impersonate Administrator*.
2. **Admin** (`admin@greenfield.demo`) → Students, Classes, Finance, Staff Room, Announcements.
3. **Form Master** (`math.teacher@gfd-101.demo`) → Assessments/Results for SS1A.
4. **Student** (`GFD-101` + `GFD-101-2025-0001`, PIN `SMART123`) → view report card.
5. **Parent** (`parent1@gfd-101.demo`) → Parent Portal with linked children.
